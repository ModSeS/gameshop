# База данных GameShop

`schema.sql` содержит структуру базы из исходного дампа `gameshop.sql`: таблицы, индексы, автоинкрементные ключи и внешние связи. Все шесть блоков `INSERT INTO` удалены; начальные значения счётчиков автоинкремента сброшены к стандартным.

| Таблица | Назначение |
| --- | --- |
| `accounts` | Пользователи, роли, дата регистрации и внутренний баланс |
| `games` | Предложения продавцов, цена, платформа, тип товара и статус модерации |
| `orders` | Заказы покупателей, данные выдачи, даты и статусы |
| `messages` | Переписка пользователей |
| `reviews` | Отзывы и оценки товаров |
| `favorites` | Избранные товары покупателей |

Создайте пустую базу `gameshop` и импортируйте в неё `schema.sql`. Скрипт не удаляет существующие таблицы и предназначен для первого развёртывания. В базе нет готовых учётных записей или товаров — создайте их через приложение. Порядок настройки описан в [основном README](../README.md#локальный-запуск).

Исходные записи не включены в репозиторий, поскольку содержат пароли, данные игровых аккаунтов и переписку. Не добавляйте рабочие дампы с пользовательскими данными в Git.
