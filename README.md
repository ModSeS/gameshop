# GameShop

GameShop — интернет-магазин для покупки и продажи игровых аккаунтов и ключей.

Проект объединяет каталог предложений, оформление заказов, общение между участниками и отзывы в одном веб-приложении.

## Возможности

| Роль | Доступные функции |
| --- | --- |
| Гость | Просмотр каталога и карточек товаров, поиск, фильтрация, сортировка, регистрация покупателя или продавца |
| Покупатель | Корзина, избранное, покупка товара за внутренний баланс, история заказов, переписка, отзывы и оценки |
| Продавец | Подача товаров на модерацию, управление предложениями, обработка заказов, переписка, просмотр рейтинга |
| Администратор | Модерация товаров, управление заказами, удаление товаров, отзывов и пользовательских аккаунтов |

В личном кабинете отображаются сведения об аккаунте и баланс; предусмотрена смена пароля. Каталог поддерживает фильтры по платформе и типу товара, сортировку по цене и рейтингу продавца.

Пополнение и вывод баланса реализованы как учебные операции в базе данных: пополнение прибавляет 500 единиц, вывод обнуляет баланс. Интеграции с реальной платёжной системой в исходниках нет.

## Технологии

- **PHP**, расширение **MySQLi**, PHP-сессии — серверная логика и авторизация.
- **MySQL / InnoDB** — хранение данных.
- **HTML, CSS, JavaScript, jQuery** — интерфейс.
- **Bootstrap** — оформление страниц; часть ресурсов подключается через CDN.
- **PhpStorm 2021.1.1** — среда разработки.

В заголовке исходного SQL-дампа указаны PHP 8.0.8 и MySQL 8.0.24. Это сведения об исходном окружении, а не гарантия совместимости со всеми версиями PHP и MySQL. Установка зависимостей через Composer или npm не требуется.

## Локальный запуск

Понадобятся PHP с включённым расширением `mysqli`, сервер MySQL и браузер. Для ресурсов, подключённых через CDN, нужен доступ к Интернету.

1. Скачайте репозиторий и откройте терминал в папке проекта.
2. Создайте пустую базу данных `gameshop` в phpMyAdmin либо в клиенте MySQL:

   ```sql
   CREATE DATABASE gameshop CHARACTER SET utf8mb3;
   ```

3. Выберите базу `gameshop` в phpMyAdmin и импортируйте `database/schema.sql`. Альтернатива — выполнить в интерактивном клиенте MySQL из папки проекта:

   ```sql
   USE gameshop;
   SOURCE database/schema.sql;
   ```

4. Настройте подключение в `public/db_connect.php`. В исходной версии используются `localhost`, порт `3306`, пользователь `root`, пустой пароль и база `gameshop`. Подставьте параметры своего локального сервера; не публикуйте реальные пароли в Git.
5. Запустите сервер из корня проекта:

   ```sh
   php -S 127.0.0.1:8000 -t public
   ```

6. Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000) и зарегистрируйте нужные аккаунты. После импорта схемы база пуста: готовых пользователей и товаров нет.

Для проверки панели администратора зарегистрируйте отдельный локальный аккаунт, найдите его `userID` в таблице `accounts` и присвойте ему роль `Admin`. Например, если его идентификатор равен 1:

```sql
UPDATE accounts SET Type = 'Admin' WHERE userID = 1;
```

Используйте фактический идентификатор выбранного аккаунта. Для демонстрации основного сценария создайте покупателя и продавца, добавьте товар от продавца, одобрите его в панели администратора и оформите заказ от покупателя.

## База данных

Схема содержит шесть таблиц: `accounts`, `games`, `orders`, `messages`, `reviews`, `favorites`. Их назначение описано в [database/README.md](database/README.md).

В репозиторий включена только структура исходной базы. Записи с паролями, данными игровых аккаунтов, перепиской и заказами исключены.

## Статус проекта

Текущая версия предназначена для изучения и локальной демонстрации. В исходной реализации пароли хранятся открытым текстом, а SQL-запросы собираются из строк. Перед использованием с реальными данными необходимы хеширование паролей, параметризованные запросы и проверка защиты пользовательских действий. Публикация исходников на GitHub сама по себе не запускает PHP-приложение.

Автоматизированных тестов в исходном проекте нет. Полная проверка сценариев требует запущенной базы MySQL.
